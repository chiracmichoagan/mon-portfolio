
Ce projet est un TP 1  qui va permettre de  Maîtriser les bases de Git et GitHub.

Objectif :

Apprendre à :

● Initialiser un dépôt Git

● Suivre les modifications

● Faire des commits

● Utiliser GitHub

● Pousser et récupérer du code



Le projet contient :

● un fichier README.md

● un fichier index.html

● un fichier style.css


Clonage du projet

- Prérequis : `git` installé.

- Cloner via HTTPS :


git clone https://github.com/<votre-utilisateur>/<nom-du-repo>.git


- Cloner via SSH (si configuré) :


git clone git@github.com:<votre-utilisateur>/<nom-du-repo>.git


- Se placer dans le dossier :

cd <nom-du-repo>


- Ouvrir le projet dans VS Code :


code .


Remplacez `<votre-utilisateur>` et `<nom-du-repo>` par les valeurs réelles.
